For the bundled October 5 sample, show 62.241328 USDC canonical movement against 124.482656 from naive double counting. Expand both actual movements and their system/ERC-20 log-index pairs. Show the receipt-derived 0.004999372 USDC gas charge. If the recorded bundle is refreshed, update these narrated numbers to its actual values before recording.
3. **40–65 seconds:** Open Balance & gas budget. Read the sample public address afresh; show the Fresh mainnet label, pinned block, 6-decimal display and the actual current native residual, which may be zero. Explain why any residual is not a second asset and why gas needs its own reserve. The read time depends on the public RPC and should not be edited to imply instantaneous responses. This public sample address is not presented as the project's wallet or the entrant's property.
4. **65–90 seconds:** Export evidence. Open Verify evidence and select the exported file; show integrity/arithmetic checks passing. State that this is RPC observation, not a validator or consensus proof. Optionally show `python arc_lens.py verify` on the same exported JSON as an independent implementation.
